# Portafolio de Staff + Media para Minecraft

Plantilla responsive, minimalista y en español para publicar gratis con GitHub Pages.

## Archivos
- `index.html`: contenido, secciones, enlaces y datos del perfil.
- `style.css`: diseño, colores y adaptación a móvil/PC.
- `script.js`: menú móvil y año automático.

## Personalización rápida
En `index.html`, busca y reemplaza:
- `[TU NICKNAME]` por tu nickname.
- `[DISPONIBILIDAD]` por “Disponible”, “No disponible” o tu situación real.
- `[Servidor 1]`, `[Servidor 2]`, `[Servidor 3 / Proyecto]` por servidores/proyectos reales.
- `[Tu rango o puesto]` y `[Tu rango o responsabilidad]` por tus cargos reales.
- Los párrafos de experiencia por tareas que realmente hayas realizado.
- `https://discord.com/` por tu enlace de contacto de Discord.
- `https://github.com/` por tu perfil real de GitHub.

El avatar actual usa una imagen pública de Steve como ejemplo. Puedes cambiar `Steve` en la URL `https://mc-heads.net/avatar/Steve/120` por tu nickname o reemplazar el enlace por otra imagen. Si quieres evitar una imagen externa, elimina la etiqueta `<img>` y deja visible el fallback.

## Publicar con GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `staff-portfolio`.
2. Sube `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona `main` y `/(root)`, y guarda.
6. Espera unos minutos. La web estará en `https://TU-USUARIO.github.io/staff-portfolio/`.

## Importante
- No inventes rangos, estadísticas, recomendaciones ni experiencia.
- No publiques datos personales, contraseñas ni conversaciones privadas.
- Google Fonts y el avatar necesitan internet para cargarse; el resto de la página es estático.
